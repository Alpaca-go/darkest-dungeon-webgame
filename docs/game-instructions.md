# Darkest Dungeon - 游戏说明

> 完整战役单页网页游戏。基于节点远征与压力生存机制。
> 移动端优先,支持 PWA 离线游玩。

---

## 1. 游戏目标

你将扮演「远征军」的领导者,从一座被诅咒的庄园出发,带领英雄们完成最终战役——击败「黑暗本相」,结束先祖之罪的循环。

```text
新建战役
→ 初始远征(庄园周围)
→ 经营庄园(招募 / 治疗 / 装备)
→ 培养英雄
→ 三个区域 + 三个区域 Boss
→ 最终区域「黑暗核心」
→ 最终 Boss「黑暗本相」(4 阶段)
→ 结局:胜利 / 惨胜 / 失败继续 / 战役崩溃
```

---

## 2. 节点远征

每次远征是一条**节点链**(约 6-10 个节点):

```text
起始 → 遭遇 / 奇物 / 露营 / 精英 / 岔路 / 目标
```

每个节点提供 **2-4 个选择**,每个选择都有**风险与收益**。

**关键要素:**
- **火把**:照亮前进的路,过低会触发迷途事件
- **食物**:每节点消耗,耗尽队伍饥饿
- **背包**:携带补给,不能中途补给
- **2-4 人队伍**:从名册中挑选
- **压力**:每次事件可能 +压力,过高会崩溃
- **死亡**:被击败的英雄**永久死亡**(进墓园)

---

## 3. 庄园周循环

每周自动推进:

```text
周一:新远征可用
周三:新英雄可招募
周五:治疗完成
周日:周结算(可选:治疗 / 升级 / 招募)
```

**庄园设施:**
- **治疗所**:治疗英雄压力/疾病
- **招募所**:招聘新英雄
- **装备所**:管理饰品
- **训练场**:升级英雄(经验 + 等级)

---

## 4. 压力与永久死亡

- **压力范围 0-100**;≥ 100 触发「崩溃」:英雄可能死亡 / 精神失常
- **死亡之门**(Death's Door):HP 0 时进入,30% 概率死亡;若抵抗成功,HP 1 恢复
- 死亡英雄**永久进墓园**,不可复活
- 治疗可降低压力,但有限度

---

## 5. 怪癖 / 疾病 / 饰品

| 系统 | 说明 |
|------|------|
| **怪癖**(Quirk) | 永久 buff/debuff,可能 +攻击 / +闪避 / -最大 HP |
| **疾病**(Disease) | 治疗需花费金币,治愈前持续影响战斗 |
| **饰品**(Trinket) | 可装备的物品,提供属性加成,某些有负面效果 |

**关键:** 怪癖和疾病都有**正反两面**,管理它们是长期经营的核心。

---

## 6. 区域

共 3 个普通区域(顺序自定,部分依赖前序 Boss):

| 区域 | 主题 | 推荐英雄 |
|------|------|----------|
| **失落审判者** Boss | 信念审判 | 圣骑士 / 盗贼 |
| **孢疫母巢** Boss | 疾病感染 | 医生 / 猎人 |
| **饥渊吞噬者** Boss | 饥饿腐化 | 圣骑士 / 医生 |

**区域机制:**
- 每个区域有**情报 → 调查 → 削弱 → 讨伐** 4 阶段任务链
- **情报**:揭示 Boss 弱点
- **调查**:提供战术选项
- **削弱**:永久降低 Boss 阶段数
- **讨伐**:必须击败才解锁最终区域

---

## 7. Boss 任务链

每个区域 Boss 都有完整 4 阶段任务链:

```text
情报(阅读情报) → 调查(执行调查) → 削弱(完成削弱) → 讨伐(击败 Boss)
```

**关键:** 跳过削弱也能打,但难度高很多;**完成全部削弱**让 Boss 更可击败。

---

## 8. 最终战役

击败 3 个区域 Boss 后,最终区域「黑暗核心」解锁:

```text
开启无光之门 → 穿越外层 → 摧毁 3 封印 → 最终讨伐「黑暗本相」(4 阶段)
```

**4 阶段最终 Boss:**
1. **试探与回忆**:读取情报 / 墓园
2. **多区域机制融合**:压力 / 疾病 / 流血 / 饥饿四重机制
3. **英雄个体考验**:针对每名英雄的怪癖 / 疾病 / 饰品 / 历史
4. **最终抉择**:撤退成本最高,选择决定结局

---

## 9. 结局

| 结局 | 条件 |
|------|------|
| **胜利** | 最终 Boss 击败 + 死亡 < 2 |
| **惨胜** | 最终 Boss 击败 + 死亡 ≥ 2 |
| **失败继续** | 最终 Boss 未击败 + 有存活英雄 |
| **战役崩溃** | 最终 Boss 失败 + 无可恢复英雄 |

每次战役只生成**一个结局**,不可重复。

---

## 10. 自动保存

- 每次远征结束、庄园操作、Boss 阶段、最终战役结算,都自动保存
- 存档存在浏览器 **localStorage** 中
- 退出 / 刷新 / 关闭页面后重新打开,会从存档恢复
- 不会保存 UI 状态(由 UI Store 重新初始化)

---

## 11. 存档导入 / 导出

### 导出
- 在主入口点击「导出存档」,生成带 checksum 的 JSON 文件
- 文件名:`game-save_<战役名>_v<版本>_<日期>.json`
- **建议每周导出一次**,防止意外数据丢失

### 导入
- 在主入口点击「导入存档」
- 选择 JSON 文件,预览战役信息
- 系统会**自动备份当前存档**
- 校验失败不覆盖原档
- 文件大小限制:5MB

### 删除
- 二次确认(需输入"删除"或长按)
- 自动备份后删除
- 当前会话可撤销一次

## 12. 离线模式

**首次访问时联网**,可安装 PWA 或缓存资源。

之后:
- 离线打开 → 显示「当前处于离线模式」提示
- 游戏核心功能完全可用
- 自动保存仍生效
- 恢复网络后,内容自动刷新

---

## 13. 错误报告

遇到错误时:
1. 主入口 → 错误报告导出
2. 显示**隐私说明**(不包含账号/邮箱/位置)
3. 玩家主动确认
4. 生成 `diagnostic-bundle_<日期>_<版本>.json`
5. 发送给开发团队复现

---

## 14. 永久死亡

**这是核心机制**。游戏不可"读档改命"。

每次战役英雄死亡**永久进墓园**,新档从头开始。

> 设计意图:每个英雄的选择都有后果,资源管理比技术更重要。

---

## 15. 推荐入门流程

1. **新档** → 取战役名 → 永久死亡说明确认
2. **第一周**:做 1 次小远征(2-3 节点)+ 招募 1 名新英雄
3. **第二周**:4 人小远征 + 1 次治疗
4. **第三周**:中型远征(5-6 节点)
5. **每 2 周** 保存一次 + 导出存档
6. **遇到 Boss** 先做情报,再考虑调查,再考虑削弱,最后讨伐

---

## 16. 失败后怎么办?

```text
老兵死亡 → 招募新人培养
金币不足 → 接受低收益任务 / 卖出饰品
补给不足 → 小型任务为主
治疗中 → 小型任务等待
Boss 失败 → 可重试(不消耗 Boss 状态)
```

**关键:** 永远可以招募新人、卖出饰品、接受低风险任务。**不存在永久软锁**。
