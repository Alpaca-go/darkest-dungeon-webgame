# Privacy Notice — 暗域远征 1.0

> 最后更新:2026-08-04
> 适用版本:0.9.0-rc1 / 1.0.0
> 项目类型:单机、离线优先、浏览器本地存档的网页游戏

---

## 1. 我们的承诺

**暗域远征 不收集任何用户数据。**

本项目为单机网页游戏,**无后端服务器**,**无账号系统**,**无云存档**,**无在线遥测**。

---

## 2. 数据存储

### 2.1 存档位置

游戏进度**仅保存在你的浏览器本地存储(localStorage)**:

| 键 | 内容 |
|----|------|
| `dd-web-expedition-save-v7` | 主存档(GameState) |
| `dd-web-expedition-save-backup` | 自动备份 |
| `dd-web-expedition-save-last-good` | 最后合法快照 |
| `dd-web-settings-v6` | UI 设置(动效 / 调试开关) |

### 2.2 存档包含什么

- 完整游戏状态(英雄 / 进度 / Boss / 最终战役)
- 战役名 / 周数 / 货币 / 任务状态
- **不包含** 任何个人信息(姓名 / 邮箱 / 手机 / 位置)

### 2.3 存档不包含什么

- ❌ 浏览器账号信息
- ❌ 邮箱 / 电话
- ❌ 精确位置
- ❌ 浏览历史
- ❌ 第三方网站数据

---

## 3. 网络请求

### 3.1 默认情况

游戏运行时**不发起任何网络请求**。

### 3.2 主动操作

只有**玩家主动**触发时才会上传数据:

| 操作 | 是否上传 |
|------|----------|
| 主动导出存档 | ❌ 仅下载到本地 |
| 主动导入存档 | ❌ 仅本地读取 |
| 主动导出诊断包 | ❌ 仅下载到本地 |
| 主动分享 URL 参数 | ❌ 浏览器本地 |

**没有任何自动上传**。

---

## 4. Service Worker 缓存

游戏使用 Service Worker 缓存资源以支持**离线游玩**:

- 缓存内容:HTML / JS / CSS / SVG / PNG
- 缓存版本:与构建版本绑定
- **不缓存** 任何 API 响应 / 第三方请求
- **不缓存** localStorage 数据

---

## 5. 诊断包(玩家主动导出)

玩家可主动导出诊断包发送给开发团队:

### 5.1 包含什么

- 构建版本 / Schema 版本
- User Agent / 视口尺寸 / 语言
- 存档元数据(周数 / 英雄数 / 金币 / Boss 进度)**不含完整存档**
- 最近事件 ID 列表(不含内容)
- 最近错误日志(**已脱敏**:邮箱/电话/密钥自动替换)
- Invariant 失败列表

### 5.2 不包含什么

- 浏览器账号信息
- 个人姓名 / 邮箱 / 位置
- 无关浏览历史
- 第三方网站数据

### 5.3 脱敏规则

| 模式 | 替换为 |
|------|--------|
| 邮箱地址 (xxx@yyy.zz) | `[EMAIL]` |
| 电话 (xxx-xxx-xxxx) | `[PHONE]` |
| API key (sk_live_xxx) | `[API_KEY]` |
| AWS access key (AKIA...) | `[AWS_KEY]` |
| password=xxx / secret=xxx | `[REDACTED]` |

### 5.4 隐私确认

导出诊断包前,玩家会看到**明确的隐私说明**,主动确认后才会生成。

---

## 6. 清除数据

### 6.1 玩家清除

- **浏览器设置** → 清除站点数据 → 选择本游戏站点 → 确认
- **游戏内** → 导出存档 → 删除存档(二次确认 + 备份)

### 6.2 卸载 PWA

- iOS:长按图标 → 移除 App
- Android:长按图标 → 卸载
- 桌面:Chrome → 设置 → 卸载

**卸载会清除所有 localStorage 数据**。

### 6.3 浏览器隐私模式

隐私模式下的存档**不持久化**,关闭后清除。

## 8. 未成年保护

本项目**不面向 13 岁以下儿童**。

- 不收集任何个人信息,因此无法识别用户年龄
- 无广告 / 无内购 / 无社交功能
- 玩家自行决定是否游玩

---

## 9. GDPR / CCPA 合规

由于**不收集任何用户数据**,本项目**自动符合** GDPR / CCPA / 各国数据保护法:

- 无需用户同意(无数据收集)
- 无需数据访问请求(无数据存储)
- 无需数据删除请求(玩家本地控制)
- 无需数据可携性(玩家可主动导出)
